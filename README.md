# Ami Travel — прототип платформы активных путешествий

Интерактивный прототип продукта: подбор маршрута, каталог с фильтрами,
карточка тура, бронирование и профиль с уровнями.

**Демо:** https://USERNAME.github.io/ami\-travel/

* * *

## Что это

Ami Travel — концепция цифровой экосистемы внутреннего туризма в России.
Проект разрабатывался командой из шести человек для всероссийского студенческого
конкурса: прошёл отборочный тур и был представлен от региона в Москве.

Прототип показывает, как продуктовые решения из исследования выглядят в интерфейсе.

## Продуктовая логика

Исследование (собственный опрос, N \= 350) показало, что барьер рынка — не цена
и не отсутствие желания, а **стоимость выбора**\:

| Метрика | Результат |
| --- | --- |
| Затруднения при поиске туров | 79% |
| Используют 3\+ сайта для поиска одной поездки | 65% |
| Хотят единую платформу с проверенными турами | 89% |
| Важны безопасность и прозрачность | 86% |
| Готовы путешествовать чаще при упрощённом поиске | 71% |
| Заинтересованы в игровых механиках | 52% |

Отсюда три решения, реализованные в прототипе:

1. **Подбор вместо поиска.** Пять вопросов про уровень, риск, длительность,
   бюджет и мотивацию — на выходе маршруты, отсортированные по совпадению.
   Пользователь не формулирует запрос, он отвечает на вопросы о себе.
2. **Прозрачность как интерфейс.** На карточке тура видно, что входит в цену
   и что придётся доплатить — двумя колонками. Гид с меткой модерации, опытом
   и отзывами.
3. **Удержание через уровни, а не через скидки.** Пройденный маршрут даёт опыт,
   уровень и бейдж за тип активности. Уровень открывает закрытые туры —
   это дешевле для юнит\-экономики, чем скидочные войны.

## Функциональность прототипа

- подбор маршрута по 5 вопросам со скорингом и процентом совпадения
- каталог: фильтры по активности, сложности, длительности и бюджету,
  сортировка, поиск, активные фильтры чипсами, пустое состояние
- карточка маршрута: программа по дням, состав цены, профиль гида, отзывы
- бронирование в два шага с пересчётом суммы и валидацией
- профиль: уровень, шкала опыта, бейджи, история поездок, избранное
- адаптив, доступность с клавиатуры, поддержка prefers\-reduced\-motion

## Технически

Один самодостаточный HTML\-файл: vanilla JS без фреймворков и сборки,
изображения маршрутов сгенерированы процедурно и встроены в файл.
Внешних зависимостей нет, кроме шрифтов Google Fonts. Работает офлайн.

Данные маршрутов, гидов и отзывов — демонстрационные.
Оплата не проводится, состояние хранится в памяти вкладки.

## Локальный запуск

Скачать `index.html` и открыть в браузере. Сборка не требуется.
